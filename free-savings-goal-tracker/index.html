Saving for several things at once usually means one savings account and a vague sense of how much of it is “for” each goal. This tracker gives every goal its own line, so you can see at a glance which ones are nearly there and which need more each month. It’s the simplest way to run sinking funds without opening a dozen accounts.

What’s in the free savings goal tracker template

The workbook has a main tab where you do everything and a How to use tab with one-page instructions. Here’s what you get:

  • Up to seven goals, each with a name, target amount and target date.
  • Saved so far and left to save for every goal, with totals across all of them.
  • A progress bar made of ten blocks that fill in as you save (built with conditional formatting, so it shows in Google Sheets as well as Excel). A goal at 100% turns green.
  • Months left until each target date, counted from the current month.
  • Save per month: left to save ÷ months left. The total at the bottom is your whole monthly savings plan.
  • A red flag when a target month has arrived and money is still needed.

The five goals in the yellow cells (an emergency fund, a holiday, an annual insurance bill, a laptop and next Christmas) are sample data, labelled at the top of the sheet. Type over them and the rest recalculates.

How to open it in Google Sheets

The template is a standard Excel file (.xlsx). Google Sheets converts it in a few seconds, and the formulas, colours and drop-downs carry over.

  1. Download the template to your computer.
  2. Go to drive.google.com, click New → File upload and choose free-savings-goal-tracker.xlsx.
  3. Right-click the uploaded file and choose Open with → Google Sheets.
  4. Click File → Save as Google Sheets. This makes a native copy you can edit on your phone and share.

Already have a spreadsheet open? File → Import → Upload works too: pick the file, then choose Insert new sheet(s).

How to use it in Excel

  1. Download the file and double-click to open it in Excel (Windows or Mac, 2016 or newer, or Microsoft 365).
  2. If a yellow Protected View bar appears, click Enable Editing. Excel shows this for every downloaded file; there are no macros in this one.
  3. Use File → Save As to save your own copy.

Prefer Excel online? Upload the file to OneDrive and open it in the browser. It also opens in LibreOffice Calc, which we used to test every formula.

How to use it, in four steps

1. List what you’re saving for

Include the big ones and the predictable irregular bills: car insurance, registration, holidays, gifts, a new phone. Give each a realistic target and a date.

2. Enter what you already have

If all your savings sit in one account, split the current balance between goals in ‘Saved so far’. The total should match your account.

3. Check the monthly total

The bottom of the Save per month column is what your goals need each month. If it’s more than you can afford, push a date back or lower a target. Watch the number change as you do.

4. Update once a month

After you move money to savings, add it to each goal’s ‘Saved so far’. You can type a sum like =3900+250 so you can see what changed. When you spend from a goal, reduce it.

Frequently asked questions

Is the savings goal tracker really free?

Yes. It’s a direct .xlsx download with no email, account or signup.

How do I use it in Google Sheets?

Download the .xlsx file, upload it to Google Drive, then right-click it and choose Open with → Google Sheets. Choose File → Save as Google Sheets for an editable copy. The progress bars use ordinary conditional formatting, so they work in Sheets.

Does it work in Excel?

Yes, in Excel for Windows and Mac, Excel for the web and LibreOffice Calc. It uses only standard formulas (SUM, IF, MAX, YEAR, MONTH, TODAY) and no macros.

How is ‘Save per month’ worked out?

It’s the amount left to save divided by the number of months from this month to the target month. If the target month has already arrived, it shows the full amount still needed in red.

Can I track a sinking fund I spend from?

Yes. When you spend from a goal, lower its ‘Saved so far’. For a recurring bill, raise the target or move the date to next year once it’s paid.

Can I add more than seven goals?

Insert a row above the ‘All goals’ total and copy the row above into it; the totals will include it. The premium tracker has room for 10 goals and a deposit log.
